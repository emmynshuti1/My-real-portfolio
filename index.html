About me

I'm an IT student and software developer at King David Academy in Rubavu, Rwanda. I learn by building practical web and desktop projects, with a growing interest in cybersecurity and secure software.

My story

My name is NSHUTI Emmanuel. My journey into technology started with a simple curiosity about how computers work and how software gets made. That curiosity turned into a habit of building, and the habit turned into a direction.

I began with C, which taught me the fundamentals — logic, memory, and how a program actually thinks. From there I moved to C++ and object-oriented programming, then to the web with HTML, CSS and JavaScript, where I could finally put something in front of people.

I build full-stack web applications with JavaScript, Node.js, Express and PostgreSQL, along with desktop software using Electron. My projects include learning and reminder tools, queue management, a home information system, and Vellura, a desktop browser.

I'm especially interested in web development, networking, secure coding and cybersecurity fundamentals. I continue developing these skills through hands-on projects and IT studies.

Goal: become a full-stack developer with genuine security expertise, building software that solves real problems in Rwanda and beyond.
